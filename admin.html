Dados do sistema

Este app guarda os dados neste navegador/aparelho (localStorage). Pedidos feitos na loja e o gerenciamento do painel funcionam quando usados no mesmo navegador — ideal para teste e uso de um único aparelho na operação. Para vários celulares/cliente+mercado em aparelhos diferentes, será necessário um servidor (back-end).
